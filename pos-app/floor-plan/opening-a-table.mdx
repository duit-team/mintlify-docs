## Step by step

<Steps>
  <Step title="Tap an available table">
    From the floor plan, tap any table showing an **Available** status.
  </Step>
  <Step title="Enter the guest count">
    Enter how many guests are being seated (pax). This is used for capacity checks and receipts.
  </Step>
  <Step title="Start adding items">
    You'll land on the menu screen for that table — tap items to add them to the bill.
  </Step>
  <Step title="Send to kitchen">
    Once you've added everything the guest ordered, tap **Send to Kitchen** to fire the order to the kitchen display or printer.
  </Step>
</Steps>

## Adding more items later

You can return to an occupied table at any time to add more items:

1. Tap the occupied table.
2. Add the new items — they'll appear under a **NEW ORDER** section, separate from what's already been sent.
3. Tap **Update** (or **Send to Kitchen**) to fire just the new items.

<Note>
  Items you haven't sent yet stay as drafts in the cart — the kitchen won't see them until you explicitly send or update.
</Note>

## Multiple bills on one table

Some tables support **multiple bills** — useful when a large table wants separate checks. Tap **Add** near the top of the cart to start a second bill on the same table.
